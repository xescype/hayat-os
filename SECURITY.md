# güvenlik

bir açık bulduysan issue açma. github'ın özel bildirim yolunu kullan:
**security → report a vulnerability**.

ne bulduğunu, nasıl tekrar edildiğini ve neyi etkilediğini kısaca yaz.
düzeltme çıkmadan ayrıntı paylaşılmaz.

desteklenen sürüm: yalnızca `main` dalı.

anahtarlar (`SODIUM_MASTER_KEY`, age private key, `.env`) hiçbir zaman repoya girmez.
bir sızıntı görürsen yine aynı yoldan haber ver.

---

**in short (english).** found a vulnerability? please don't open a public issue.
use github's private reporting (security → report a vulnerability).
only the `main` branch is supported.
